# Persoane și posesia în maghiară

## De la férfi și nép la népe

**Férfi** înseamnă „bărbat”, **nép** înseamnă „popor”, iar **népe** este o formă posesivă: „poporul lui / ei”. Nu sunt cuvinte din aceeași familie. Lecția pornește de la această diferență și explică posesia prin vocabular despre persoane și exemple cotidiene.

## Persoane, plural și familii de cuvinte

**Férfi → férfiak** („bărbat → bărbați”), **nő → nők** („femeie → femei”), **gyerek → gyerekek** („copil → copii”). După un numeral, substantivul rămâne la singular: **két férfi**, **három gyerek**. Folosește **két** înaintea substantivului; **kettő** este forma independentă pentru „doi / două”.

**Férfias** („bărbătesc, masculin”) este derivat din **férfi**. **Népi** („popular, folcloric”) și **népdal** („cântec popular”) sunt înrudite cu **nép**. În schimb, **népek** este pluralul, iar **népe** este o formă posesivă a aceluiași substantiv.

## Cum se exprimă „lui” sau „ei”

În maghiară, terminația posesivă se adaugă la lucrul posedat: **nép + -e → népe**. Termenul maghiar este **birtokos személyjel**. Aici studiem un singur lucru posedat și un posesor la persoana a III-a singular.

**Anna könyve** înseamnă „cartea Anei”: posesorul apare înainte, iar **könyv** („carte”) primește **-e**. **Isten népe** înseamnă „poporul lui Dumnezeu”. **Népe** se scrie cu literă mică în această expresie; majuscula apare la începutul propoziției sau când o cere un titlu.

**A könyve** poate însemna atât „cartea lui”, cât și „cartea ei”. Maghiara nu distinge genul posesorului prin această terminație. Pronumele **ő** poate însemna „el” sau „ea”; **az ő könyve** precizează ori accentuează posesorul. Acest **ő** nu este articolul **a / az**.

## Terminațiile -a, -e, -ja, -je

| Terminație | Formare | Sens |
| --- | --- | --- |
| -a | ház → háza | casa lui / ei |
| -e | könyv → könyve | cartea lui / ei |
| -ja | barát → barátja | prietenul lui / ei |
| -je | kert → kertje | grădina lui / ei |

Armonia vocalică ajută la alegerea dintre **a** și **e**, dar nu prezice singură prezența lui **j**. Învață perechi precum **ház – háza**, **kert – kertje**, **könyv – könyve**. Vezi și [ghidul despre armonia vocalică](./armonia-vocalica-limba-maghiara.html).

Unele rădăcini se schimbă: **név → neve**, **kéz → keze**, **víz → vize**. Vocala lungă se scurtează în aceste exemple, dar rămâne lungă în **nép → népe**. În **alma → almája** și **körte → körtéje**, vocala finală se lungește înaintea terminației.

## Articole și propoziții utile

Articolul hotărât este **a** înaintea unei consoane și **az** înaintea unei vocale: **a férfi**, **az ember**. Se ia în calcul cuvântul imediat următor: **az ország népe**, dar **a magyar nép**. Numele proprii apar de obicei fără articol în modelul de aici: **Anna könyve**, **Péter barátja**.

**Ez Anna könyve.** — Aceasta este cartea Anei. La persoana a III-a, în prezent, o identificare ca aceasta nu folosește **van**. Pentru localizare însă: **Anna könyve itt van.** — Cartea Anei este aici.

**Ki ő?** întreabă „Cine este el / ea?”. **Kinek a könyve ez?** întreabă „A cui este această carte?”. **Kinek** înseamnă aici „al cui / a cui”. În răspunsul **Ez Anna könyve**, numele Anna nu primește o terminație. Există și construcția **Annának a könyve**, utilă ca extensie după ce stăpânești modelul simplu.

## Cum le pronunți

Accentul maghiar cade pe prima silabă. **Férfi** se desparte **fér-fi**, iar **népe**, **né-pe**. **É** este o vocală lungă, mai închisă decât **e**; lungimea vocalei nu mută accentul. Pentru sunetele **ő**, **ű**, **gy** și celelalte litere, consultă [alfabetul maghiar](./alfabet-maghiar.html).

## Exerciții

Completează cu **férfi**, **nép** sau **népe**.

1. egy ______ — un bărbat
2. a magyar ______ — poporul maghiar
3. Isten ______ — poporul lui Dumnezeu

Alege forma potrivită.

1. Anna (könyv / könyve) — cartea Anei
2. Péter (barát / barátja) — prietenul lui Péter
3. a gyerek (kéz / keze) — mâna copilului
4. két (férfi / férfiak) — doi bărbați
5. a lány (név / neve) — numele fetei

Tradu în maghiară.

1. Aceasta este grădina Anei.
2. Cartea Anei este aici.
3. A cui este această casă?

### Răspunsuri

Completare: **1. férfi; 2. nép; 3. népe**.

Alegere: **1. könyve; 2. barátja; 3. keze; 4. férfi; 5. neve**.

Traducere: **1. Ez Anna kertje. 2. Anna könyve itt van. 3. Kinek a háza ez?**
