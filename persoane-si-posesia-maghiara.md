# Persoane și posesia în maghiară

## De la férfi și nép la népe

<span lang="hu">**Férfi**</span> înseamnă „bărbat”, <span lang="hu">**nép**</span> înseamnă „popor”, iar <span lang="hu">**népe**</span> este o formă posesivă: „poporul lui / ei”. Férfi și nép aparțin unor familii diferite; népe este o formă a lui nép. Lecția pornește de la această diferență și explică posesia prin vocabular despre persoane și exemple cotidiene.

## Persoane, plural și familii de cuvinte

<span lang="hu">**Férfi → férfiak**</span> („bărbat → bărbați”), <span lang="hu">**nő → nők**</span> („femeie → femei”), <span lang="hu">**gyerek → gyerekek**</span> („copil → copii”). După un numeral, substantivul rămâne la singular: <span lang="hu">**két férfi**</span>, <span lang="hu">**három gyerek**</span>. Folosește <span lang="hu">**két**</span> înaintea substantivului; <span lang="hu">**kettő**</span> este forma independentă pentru „doi / două”.

<span lang="hu">**Férfias**</span> („bărbătesc, masculin”) este derivat din <span lang="hu">**férfi**</span>. <span lang="hu">**Népi**</span> („popular, folcloric”) și <span lang="hu">**népdal**</span> („cântec popular”) sunt înrudite cu <span lang="hu">**nép**</span>. În schimb, <span lang="hu">**népek**</span> este pluralul, iar <span lang="hu">**népe**</span> este o formă posesivă a aceluiași substantiv.

## Cum se exprimă „lui” sau „ei”

În maghiară, terminația posesivă se adaugă la lucrul posedat: <span lang="hu">**nép + -e → népe**</span>. Termenul maghiar este <span lang="hu">**birtokos személyjel**</span>. Pornim de la un singur lucru posedat și un posesor la persoana a III-a singular; mai jos introducem și „am / ai”.

<span lang="hu">**Anna könyve**</span> înseamnă „cartea Anei”: posesorul apare înainte, iar <span lang="hu">**könyv**</span> („carte”) primește <span lang="hu">**-e**</span>. <span lang="hu">**Isten népe**</span> înseamnă „poporul lui Dumnezeu”. <span lang="hu">**Népe**</span> se scrie cu literă mică în această expresie; majuscula apare la începutul propoziției sau când o cere un titlu.

<span lang="hu">**A könyve**</span> poate însemna atât „cartea lui”, cât și „cartea ei”. Maghiara nu distinge genul posesorului prin această terminație. Pronumele <span lang="hu">**ő**</span> poate însemna „el” sau „ea”; <span lang="hu">**az ő könyve**</span> precizează ori accentuează posesorul. Acest <span lang="hu">**ő**</span> nu este articolul <span lang="hu">**a / az**</span>.

## Terminațiile -a, -e, -ja, -je

| Terminație | Formare | Sens |
| --- | --- | --- |
| -a | ház → háza | casa lui / ei |
| -e | könyv → könyve | cartea lui / ei |
| -ja | barát → barátja | prietenul lui / ei |
| -je | kert → kertje | grădina lui / ei |

Armonia vocalică ajută la alegerea dintre <span lang="hu">**a**</span> și <span lang="hu">**e**</span>, dar nu prezice singură prezența lui <span lang="hu">**j**</span>. Învață perechi precum <span lang="hu">**ház – háza**</span>, <span lang="hu">**kert – kertje**</span>, <span lang="hu">**könyv – könyve**</span>. Vezi și [ghidul despre armonia vocalică](./armonia-vocalica-limba-maghiara.html).

Unele rădăcini se schimbă: <span lang="hu">**név → neve**</span>, <span lang="hu">**kéz → keze**</span>, <span lang="hu">**víz → vize**</span>. Vocala lungă se scurtează în aceste exemple, dar rămâne lungă în <span lang="hu">**nép → népe**</span>. În <span lang="hu">**alma → almája**</span> și <span lang="hu">**körte → körtéje**</span>, vocala finală se lungește înaintea terminației.

## Articole și propoziții utile

Articolul hotărât este <span lang="hu">**a**</span> înaintea unei consoane și <span lang="hu">**az**</span> înaintea unei vocale: <span lang="hu">**a férfi**</span>, <span lang="hu">**az ember**</span>. Se ia în calcul cuvântul imediat următor: <span lang="hu">**az ország népe**</span>, dar <span lang="hu">**a magyar nép**</span>. Numele proprii apar de obicei fără articol în modelul de aici: <span lang="hu">**Anna könyve**</span>, <span lang="hu">**Péter barátja**</span>.

<span lang="hu">**Ez Anna könyve.**</span> — Aceasta este cartea Anei. La persoana a III-a, în prezent, o identificare ca aceasta nu folosește <span lang="hu">**van**</span>. Pentru localizare însă: <span lang="hu">**Anna könyve itt van.**</span> — Cartea Anei este aici.

<span lang="hu">**Ki ő?**</span> întreabă „Cine este el / ea?”. <span lang="hu">**Kinek a könyve ez?**</span> întreabă „A cui este această carte?”. <span lang="hu">**Kinek**</span> înseamnă aici „al cui / a cui”. În răspunsul <span lang="hu">**Ez Anna könyve**</span>, numele Anna nu primește o terminație. Există și construcția <span lang="hu">**Annának a könyve**</span>, utilă ca extensie după ce stăpânești modelul simplu.

## Cum spui „am” și „nu am”

Pentru un singur lucru posedat, folosește <span lang="hu">**van / nincs**</span> și substantivul cu terminație posesivă: <span lang="hu">**Van egy könyvem.**</span> — Am o carte. <span lang="hu">**Nincs könyvem.**</span> — Nu am carte. <span lang="hu">**-m**</span> indică posesorul „eu”, iar <span lang="hu">**-d**</span>, posesorul „tu”: <span lang="hu">**Van egy könyved?**</span> — Ai o carte?

Cu un nume explicit: <span lang="hu">**Annának van egy könyve.**</span> — Anna are o carte. Numele primește <span lang="hu">**-nak / -nek**</span>, iar lucrul posedat păstrează terminația posesivă. Nu confunda această construcție cu <span lang="hu">**Anna könyve itt van**</span>, care localizează cartea.

## Cum le pronunți

Accentul maghiar cade pe prima silabă. <span lang="hu">**Férfi**</span> se desparte <span lang="hu">**fér-fi**</span>, iar <span lang="hu">**népe**</span>, <span lang="hu">**né-pe**</span>. <span lang="hu">**É**</span> este o vocală lungă, mai închisă decât <span lang="hu">**e**</span>; lungimea vocalei nu mută accentul. Pentru sunetele <span lang="hu">**ő**</span>, <span lang="hu">**ű**</span>, <span lang="hu">**gy**</span> și celelalte litere, consultă [alfabetul maghiar](./alfabet-maghiar.html).

## Exerciții

Completează cu <span lang="hu">**férfi**</span>, <span lang="hu">**nép**</span> sau <span lang="hu">**népe**</span>.

1. egy ______ — un bărbat
2. a magyar ______ — poporul maghiar
3. Isten ______ — poporul lui Dumnezeu

Alege forma potrivită.

1. Anna (könyv / könyve) — cartea Anei
2. Péter (barát / barátja) — prietenul lui Péter
3. a gyerek (kéz / keze) — mâna copilului
4. két (férfi / férfiak) — doi bărbați
5. a lány (név / neve) — numele fetei

Tradu în maghiară.

1. Aceasta este grădina Anei.
2. Cartea Anei este aici.
3. A cui este această casă?

### Răspunsuri

Completare: <span lang="hu">**1. férfi; 2. nép; 3. népe**</span>.

Alegere: <span lang="hu">**1. könyve; 2. barátja; 3. keze; 4. férfi; 5. neve**</span>.

Traducere: <span lang="hu">**1. Ez Anna kertje. 2. Anna könyve itt van. 3. Kinek a háza ez?**</span>
