# Fișă de studiu: armonia vocalică în limba maghiară (A1–C2)

**Termeni maghiari:** <span lang="hu">*magánhangzó-harmónia*</span> („armonie vocalică”), <span lang="hu">*hangrend*</span> („tiparul vocalic al cuvântului”), <span lang="hu">*illeszkedés*</span> („adaptarea armonică a sufixului”).
**Public:** vorbitori de română care studiază maghiara.  
**Convenție:** segmentele separate prin `+` ilustrează structura morfologică, nu scrierea corectă; formele maghiare se scriu de regulă fără aceste semne.  
**Surse:** trimiterile `[1]`, `[2]` etc. conduc la bibliografia integrală din secțiunea 16.

## 1. Ideea fundamentală (A1)

**Armonia vocalică** este tendința unor vocale dintr-un cuvânt, în special a vocalelor din sufixe, de a se potrivi cu anumite trăsături ale vocalelor din rădăcină. Nu este o regulă potrivit căreia toate vocalele trebuie să fie identice.

Maghiara este o limbă aglutinantă: informații pe care româna le exprimă prin prepoziții sau cuvinte separate apar adesea prin sufixe:

| Cuvânt de bază | Cu sufix | Traducere | Ce s-a întâmplat? |
|---|---|---|---|
| <span lang="hu">`ház`</span> | <span lang="hu">`házban`</span> | în casă | sufixul este <span lang="hu">`-ban`</span> |
| <span lang="hu">`kert`</span> | <span lang="hu">`kertben`</span> | în grădină | același caz, dar <span lang="hu">`-ben`</span> |
| <span lang="hu">`ház`</span> | <span lang="hu">`házhoz`</span> | către casă | sufixul este <span lang="hu">`-hoz`</span> |
| <span lang="hu">`kert`</span> | <span lang="hu">`kerthez`</span> | către grădină | sufixul este <span lang="hu">`-hez`</span> |
| <span lang="hu">`tűz`</span> | <span lang="hu">`tűzhöz`</span> | către foc | sufixul este <span lang="hu">`-höz`</span> |

**Regula practică de început:** dacă rădăcina are vocale posterioare, alegem frecvent sufixul posterior; dacă are vocale anterioare, alegem frecvent sufixul anterior. Există însă vocale neutre, cuvinte mixte și excepții lexicale. [1], [2]

## 2. Cele 14 vocale maghiare (A1)

Limba maghiară standard are **14 vocale grafice/foneme vocalice**, repartizate în șapte perechi tradiționale de vocale scurte și lungi. Diferența de lungime este importantă, dar perechile <span lang="hu">`a/á`</span> și <span lang="hu">`e/é`</span> diferă și prin calitatea sunetului. [2], [3]

| Literă | IPA aproximativ | Tip articulator | Exemplu |
|---|---|---|---|
| <span lang="hu">`a`</span> | /ɒ/ | posterioară, scurtă, rotunjită | <span lang="hu">`alma`</span> – măr |
| <span lang="hu">`á`</span> | /aː/ | posterioară în sistemul fonologic, lungă | <span lang="hu">`ház`</span> – casă |
| <span lang="hu">`o`</span> | /o/ | posterioară, rotunjită | <span lang="hu">`bor`</span> – vin |
| <span lang="hu">`ó`</span> | /oː/ | posterioară, rotunjită, lungă | <span lang="hu">`tó`</span> – lac |
| <span lang="hu">`u`</span> | /u/ | posterioară, rotunjită | <span lang="hu">`kutya`</span> – câine |
| <span lang="hu">`ú`</span> | /uː/ | posterioară, rotunjită, lungă | <span lang="hu">`út`</span> – drum |
| <span lang="hu">`e`</span> | /ɛ/ | anterioară, nerotunjită | <span lang="hu">`ember`</span> – om |
| <span lang="hu">`é`</span> | /eː/ | anterioară, nerotunjită, lungă | <span lang="hu">`kép`</span> – imagine |
| <span lang="hu">`i`</span> | /i/ | anterioară, nerotunjită | <span lang="hu">`kis`</span> – mic |
| <span lang="hu">`í`</span> | /iː/ | anterioară, nerotunjită, lungă | <span lang="hu">`víz`</span> – apă |
| <span lang="hu">`ö`</span> | /ø/ | anterioară, rotunjită | <span lang="hu">`öt`</span> – cinci |
| <span lang="hu">`ő`</span> | /øː/ | anterioară, rotunjită, lungă | <span lang="hu">`őz`</span> – căprior |
| <span lang="hu">`ü`</span> | /y/ | anterioară, rotunjită | <span lang="hu">`üveg`</span> – sticlă |
| <span lang="hu">`ű`</span> | /yː/ | anterioară, rotunjită, lungă | <span lang="hu">`tűz`</span> – foc |

**Cum pronunți <span lang="hu">`ö`</span> și <span lang="hu">`ü`</span>:** pentru <span lang="hu">`ö`</span>, încearcă să rostești un <span lang="hu">`e`</span> mai închis, rotunjind buzele; pentru <span lang="hu">`ü`</span>, păstrează poziția limbii de la <span lang="hu">`i`</span>, dar rotunjește buzele. Sunetele nu au echivalente exacte în româna standard. Semnul dublu-accent <span lang="hu">`ő/ű`</span> indică lungimea, nu două silabe și nici accentul tonic. Accentul lexical maghiar cade, în mod obișnuit, pe prima silabă.

### Cele două grupuri mari

| Vocale posterioare (<span lang="hu">*mély hangrendű*</span>) | Vocale anterioare (<span lang="hu">*magas hangrendű*</span>) |
|---|---|
| **a, á, o, ó, u, ú** | **e, é, i, í, ö, ő, ü, ű** |

**Atenție:** „magas” în terminologia școlară maghiară înseamnă **anterior**, iar „mély” înseamnă **posterior**. Nu descriu neapărat vocale înalte sau joase din punct de vedere fonetic. [1], [3]

## 3. Două tipuri de armonie (A1–A2)

1. **Armonie de anterioritate/posterioritate** (<span lang="hu">*elölségi*</span>, tradițional <span lang="hu">*palatoveláris*</span>): determină, de exemplu, alegerea dintre <span lang="hu">`-ban`</span> și <span lang="hu">`-ben`</span>. Este mecanismul cel mai răspândit.
2. **Armonie de rotunjire a buzelor** (<span lang="hu">*kerekségi*</span>, <span lang="hu">*labiális*</span>): contează doar pentru anumite sufixe cu trei variante, de exemplu <span lang="hu">`-hoz/-hez/-höz`</span>. În maghiara standard, aceasta funcționează în interiorul seriei vocalelor anterioare. [2], [4]

De aceea **<span lang="hu">`kerthez`</span>**, dar **<span lang="hu">`tűzhöz`</span>**: ambele cuvinte sunt anterioare; numai al doilea are o vocală anterioară rotunjită care determină <span lang="hu">`-höz`</span>.

## 4. Sufixe cu două variante (A1–A2)

| Sens / funcție | Sufix posterior | Sufix anterior | Exemplu posterior | Exemplu anterior |
|---|---|---|---|---|
| în, la interior | <span lang="hu">`-ban`</span> | <span lang="hu">`-ben`</span> | <span lang="hu">`házban`</span> | <span lang="hu">`kertben`</span> |
| deplasare în interior | <span lang="hu">`-ba`</span> | <span lang="hu">`-be`</span> | <span lang="hu">`házba`</span> | <span lang="hu">`kertbe`</span> |
| din interior | <span lang="hu">`-ból`</span> | <span lang="hu">`-ből`</span> | <span lang="hu">`házból`</span> | <span lang="hu">`kertből`</span> |
| de la | <span lang="hu">`-tól`</span> | <span lang="hu">`-től`</span> | <span lang="hu">`háztól`</span> | <span lang="hu">`kerttől`</span> |
| de pe / despre | <span lang="hu">`-ról`</span> | <span lang="hu">`-ről`</span> | <span lang="hu">`házról`</span> | <span lang="hu">`kertről`</span> |
| spre / pe | <span lang="hu">`-ra`</span> | <span lang="hu">`-re`</span> | <span lang="hu">`házra`</span> | <span lang="hu">`kertre`</span> |
| dativ: cui? | <span lang="hu">`-nak`</span> | <span lang="hu">`-nek`</span> | <span lang="hu">`háznak`</span> | <span lang="hu">`kertnek`</span> |
| cu (instrumental/sociativ) | <span lang="hu">`-val`</span> | <span lang="hu">`-vel`</span> | <span lang="hu">`házzal`</span> | <span lang="hu">`kerttel`</span> |
| „-ime”, abstractizare | <span lang="hu">`-ság`</span> | <span lang="hu">`-ség`</span> | <span lang="hu">`barátság`</span> – prietenie | <span lang="hu">`szépség`</span> – frumusețe |
| posibilitate verbală | <span lang="hu">`-hat`</span> | <span lang="hu">`-het`</span> | <span lang="hu">`olvashat`</span> – poate citi | <span lang="hu">`kérhet`</span> – poate cere |

**Detaliu de ortografie:** la <span lang="hu">`-val/-vel`</span>, consoana <span lang="hu">`v`</span> se asimilează adesea consoanei finale a cuvântului: <span lang="hu">`ház + val → házzal`</span>; <span lang="hu">`kert + vel → kerttel`</span>. Aceasta este o regulă consonantică suplimentară, nu armonie vocalică. [1]

## 5. Sufixe cu trei variante (A2)

| Seria | După vocale posterioare | După anterioare nerotunjite | După anterioare rotunjite |
|---|---|---|---|
| <span lang="hu">`-hoz/-hez/-höz`</span> („către”) | <span lang="hu">`házhoz`</span> | <span lang="hu">`székhez`</span> | <span lang="hu">`tűzhöz`</span> |
| <span lang="hu">`-on/-en/-ön`</span> („pe”) | <span lang="hu">`házon`</span> | <span lang="hu">`széken`</span> | <span lang="hu">`tűzön`</span> |
| <span lang="hu">`-szor/-szer/-ször`</span> („de ... ori”) | <span lang="hu">`háromszor`</span> | <span lang="hu">`kétszer`</span> | <span lang="hu">`ötször`</span> |

**Cazul special <span lang="hu">`-n`</span>:** după anumite rădăcini terminate în vocală, cazul superesiv are forma <span lang="hu">`-n`</span>: <span lang="hu">`Buda → Budán`</span>, <span lang="hu">`Gyula → Gyulán`</span>, <span lang="hu">`Gödöllő → Gödöllőn`</span>. Observă și prelungirea lui <span lang="hu">`a → á`</span>.

**Nu este suficient să numeri vocalele rotunjite din tot cuvântul.** Comparația <span lang="hu">`könyvhöz`</span> („către carte”) – <span lang="hu">`könyvekhez`</span> („către cărți”) arată că vocala anterioară nerotunjită <span lang="hu">`e`</span> din plural poate determina forma <span lang="hu">`-hez`</span>, chiar dacă rădăcina <span lang="hu">`könyv`</span> conține <span lang="hu">`ö`</span>. Vezi secțiunea 12. [2], [6]

## 6. Sufixe cu patru realizări și vocale de legătură (B1)

Unele terminații apar cu **a/e/o/ö**. Pentru substantive, diferențele nu sunt toate explicabile doar prin armonie: intervine și **clasa flexionară a rădăcinii**, inclusiv așa-numitele *nyitótövek* („rădăcini deschise”). [5]

| Substantiv | Plural | Acuzativ | Observație |
|---|---|---|---|
| <span lang="hu">`ház`</span> – casă | <span lang="hu">`házak`</span> | <span lang="hu">`házat`</span> | apare <span lang="hu">`a`</span> |
| <span lang="hu">`kert`</span> – grădină | <span lang="hu">`kertek`</span> | <span lang="hu">`kertet`</span> | apare <span lang="hu">`e`</span> |
| <span lang="hu">`gáz`</span> – gaz | <span lang="hu">`gázok`</span> | <span lang="hu">`gázt`</span> | plural cu <span lang="hu">`o`</span>, dar acuzativ fără vocală de legătură |
| <span lang="hu">`kürt`</span> – corn, trompetă | <span lang="hu">`kürtök`</span> | <span lang="hu">`kürtöt`</span> | apare <span lang="hu">`ö`</span> |

Pentru o comparație regulată cu <span lang="hu">`o`</span>, folosește **<span lang="hu">`ablak`</span> („fereastră”) → <span lang="hu">`ablakok`</span> (plural), <span lang="hu">`ablakot`</span> (acuzativ)**.

Perechea **<span lang="hu">`házak`</span> / <span lang="hu">`gázok`</span>** este esențială: ambele rădăcini au vocala <span lang="hu">`á`</span>, dar aleg <span lang="hu">`a`</span>, respectiv <span lang="hu">`o`</span>, din motive de clasă flexionară, nu din cauza armoniei. [5]

La unele substantive terminate deja în vocală, pluralul adaugă direct <span lang="hu">`-k`</span>: <span lang="hu">`autó → autók`</span>, <span lang="hu">`alma → almák`</span>, <span lang="hu">`körte → körték`</span>. Vocalele scurte finale <span lang="hu">`a/e`</span> se lungesc frecvent înaintea sufixelor: <span lang="hu">`alma → almában`</span>, <span lang="hu">`körte → körtében`</span>.

## 7. Vocale neutre: i, í, é și e (B1)

În fonetică, toate patru sunt **anterioare**. În armonia de anterioritate/posterioritate, însă, pot funcționa ca **vocale neutre** (*semleges magánhangzók*): permit în anumite situații unui sufix să urmeze o vocală posterioară aflată mai devreme în cuvânt. Nu toate sunt la fel de neutre. [2], [4], [7]

Exemple de **transparență** (*áttetszőség*):

| Rădăcină | Tipar | Formă corectă | De ce? |
|---|---|---|---|
| <span lang="hu">`papír`</span> – hârtie | <span lang="hu">`a + í`</span> | <span lang="hu">`papírnak`</span> | <span lang="hu">`í`</span> nu blochează influența lui <span lang="hu">`a`</span> |
| <span lang="hu">`kocsi`</span> – mașină | <span lang="hu">`o + i`</span> | <span lang="hu">`kocsiban`</span> | <span lang="hu">`i`</span> este transparent |
| <span lang="hu">`kávé`</span> – cafea | <span lang="hu">`á + é`</span> | <span lang="hu">`kávéban`</span> | <span lang="hu">`é`</span> poate fi transparent |
| <span lang="hu">`tányér`</span> – farfurie | <span lang="hu">`á + é`</span> | <span lang="hu">`tányérnak`</span> | <span lang="hu">`é`</span> nu impune automat <span lang="hu">`-nek`</span> |

Faptul că ultima vocală vizibilă este <span lang="hu">`i`</span>, <span lang="hu">`í`</span> sau <span lang="hu">`é`</span> **nu garantează** că vom folosi sufix anterior.

**Scară aproximativă a neutralității**, de la transparență mai robustă la transparență mai puțin robustă:

<span lang="hu">`i / í  >  é  >  e`</span>

În termenii studiilor fonologice, aceasta este o tendință **statistică și lexicală**, nu o formulă mecanică pentru fiecare cuvânt. [4], [7], [8]

## 8. Cuvinte cu vocale mixte (B1–B2)

**Vegyes hangrendű szavak** sunt cuvintele care conțin și vocale anterioare, și vocale posterioare. Ele nu sunt automat „greșite”.

| Cuvânt | Semnificație | Sufix | Observație |
|---|---|---|---|
| <span lang="hu">`papír`</span> | hârtie | <span lang="hu">`papírban`</span> | neutralitate a lui <span lang="hu">`í`</span> |
| <span lang="hu">`kávé`</span> | cafea | <span lang="hu">`kávéban`</span> | <span lang="hu">`é`</span> transparent în acest cuvânt |
| <span lang="hu">`koncert`</span> | concert | <span lang="hu">`koncerten`</span> | sufix anterior, deși există <span lang="hu">`o`</span> |
| <span lang="hu">`sofőr`</span> | șofer | <span lang="hu">`sofőrnek`</span> | <span lang="hu">`ő`</span> final antrenează seria anterioară |
| <span lang="hu">`fotel`</span> | fotoliu | <span lang="hu">`fotelban`</span> / <span lang="hu">`fotelben`</span> | variante documentate în uz și în studii |

**Metoda sigură:** nu deduce mecanic sufixul numai din ultima literă. Pentru împrumuturi, nume proprii sau cuvinte mixte, învață și o formă cu sufix, de exemplu <span lang="hu">`koncert – koncerten`</span>. [1], [4], [7]

## 9. Antiharmonia: excepții care au propria regulă (B2)

**Antiharmonia** (*antiharmónia*) apare când o rădăcină ce conține numai vocale neutre anterioare cere totuși un sufix **posterior**.

| Rădăcină | Română | Formă de reținut |
|---|---|---|
| <span lang="hu">`híd`</span> | pod | <span lang="hu">`hídnak`</span>, <span lang="hu">`hídon`</span> |
| <span lang="hu">`cél`</span> | scop, țintă | <span lang="hu">`célnak`</span>, <span lang="hu">`célhoz`</span> |
| <span lang="hu">`nyíl`</span> | săgeată | <span lang="hu">`nyílnak`</span> |
| <span lang="hu">`díj`</span> | premiu, taxă | <span lang="hu">`díjat`</span> |

În contrast, alte rădăcini alcătuite numai din vocale neutre primesc sufixe anterioare: <span lang="hu">`víznek`</span> („apei”), <span lang="hu">`szívnek`</span> („inimii”), <span lang="hu">`évnek`</span> („anului”).

**Exemplul important <span lang="hu">`férfi`</span> („bărbat”):** în anumite construcții sunt atestate ambele serii, precum <span lang="hu">`férfival / férfivel`</span>, <span lang="hu">`férfihoz / férfihez`</span>. Totuși pluralul uzual este <span lang="hu">`férfiak`</span>. Întreaga paradigmă nu se poate prezice automat dintr-o singură formă. [5], [8], [9]

## 10. Variația: nu orice alegere are un singur răspuns (B2–C1)

Unele rădăcini **oscilează** (*ingadozó toldalékolás*) între două clase armonice, iar frecvența alternativelor poate varia între vorbitori și registre.

Exemple descrise în literatura de specialitate: <span lang="hu">`fotelban / fotelben`</span>; <span lang="hu">`férfival / férfivel`</span>; în anumite contexte și <span lang="hu">`alibival / alibivel`</span>. Ele nu sunt obligatoriu la fel de frecvente sau acceptate de toți vorbitorii. [4], [7], [8]

Două tendințe avansate:

1. **Height Effect / efectul înălțimii:** în rădăcinile cu vocală posterioară urmată de vocală neutră, <span lang="hu">`i/í`</span> sunt mai transparent-neutre decât <span lang="hu">`é`</span>, iar <span lang="hu">`e`</span> este și mai predispusă să favorizeze sufixe anterioare.
2. **Count Effect / efectul numărului:** două sau mai multe vocale neutre succesive după o vocală posterioară favorizează, statistic, alegerea unui sufix anterior mai mult decât o singură vocală neutră.

Aceste rezultate nu spun că „ultima vocală decide întotdeauna”, ci că vorbitorii folosesc informație fonologică, lexicală și probabilistică. [4], [7], [8], [10]

## 11. Sufixe invariabile: armonia nu se aplică oricărui sufix (B1)

Unele sufixe au **o singură formă**, oricare ar fi rădăcina:

| Sufix | Exemplu 1 | Exemplu 2 | Sens |
|---|---|---|---|
| <span lang="hu">`-ig`</span> | <span lang="hu">`házig`</span> | <span lang="hu">`kertig`</span> | până la |
| <span lang="hu">`-ért`</span> | <span lang="hu">`házért`</span> | <span lang="hu">`kertért`</span> | pentru / în schimbul |
| <span lang="hu">`-kor`</span> | <span lang="hu">`hatkor`</span> | <span lang="hu">`ötkor`</span> | la ora ... |
| <span lang="hu">`-ni`</span> | <span lang="hu">`olvasni`</span> | <span lang="hu">`kérni`</span> | infinitiv |

Nu inventa forme precum <span lang="hu">`*-ög`</span>, <span lang="hu">`*-ort`</span> sau <span lang="hu">`*-ne`</span> din dorința de a armoniza un sufix fix. Într-o analiză lingvistică, vocalele neutre ale unor sufixe invariabile pot coexista cu vocale posterioare fără conflict. [1], [2]

## 12. Domeniul armoniei: compuse, sufixe succesive și morfologie (C1–C2)

Armonia **nu** înseamnă că fiecare vocală din orice cuvânt compus trebuie să aparțină aceluiași grup. În compuse, componentele își pot păstra propriile vocale: <span lang="hu">`könyvtár`</span> („bibliotecă”, literal „depozit de cărți”) are <span lang="hu">`ö`</span> și <span lang="hu">`á`</span>, iar forma locativă este <span lang="hu">`könyvtárban`</span>, nu <span lang="hu">`*könyvtárben`</span>.

Pentru sufixele cu trei forme, **rotunjirea poate fi locală**:

- <span lang="hu">`könyv-höz`</span> → **könyvhöz** („către carte”): ultima vocală relevantă este <span lang="hu">`ö`</span>, rotunjită;
- <span lang="hu">`könyv-ek-hez`</span> → **könyvekhez** („către cărți”): vocala de legătură <span lang="hu">`e`</span> din plural favorizează <span lang="hu">`-hez`</span>.

Când adăugăm sufixe succesive, analiza nu se reduce mereu la proprietățile rădăcinii originale. Morfologia și clasa lexicală participă la calculul formei; literatura folosește inclusiv conceptul de **Harmonic Uniformity** („uniformitate armonică” în cadrul paradigmei). [6], [10]

### De ce armonia labială este diferită?

În timp ce **armonia anterior/posterior** poate funcționa peste una sau mai multe vocale neutre, **armonia de rotunjire** este mult mai locală și nu are același mecanism de transparență. Nu trebuie tratate ca două copii identice ale aceleiași reguli. [2], [6]

## 13. Armonia la verbe (A2–B1)

Armonia se observă și în conjugare, nu numai în substantive:

| Verb, persoana I singular, prezent | Traducere | Observație |
|---|---|---|
| <span lang="hu">`olvasok`</span> | citesc | <span lang="hu">`o`</span> posterior în terminație |
| <span lang="hu">`kérek`</span> | cer | <span lang="hu">`e`</span> anterior nerotunjit |
| <span lang="hu">`főzök`</span> | gătesc | <span lang="hu">`ö`</span> anterior rotunjit |
| <span lang="hu">`tanulunk`</span> | învățăm | seria posterioară |
| <span lang="hu">`kérünk`</span> | cerem | seria anterioară |

Terminațiile verbale depind **și de persoană, număr, conjugare și clasa verbului**, nu numai de armonie. De aceea nu există o singură terminație aplicabilă tuturor verbelor cu vocale posterioare. Forma de infinitiv <span lang="hu">`-ni`</span> rămâne invariabilă: <span lang="hu">`olvasni`</span>, <span lang="hu">`kérni`</span>, <span lang="hu">`főzni`</span>.

## 14. Legătura cu numele orașelor: două alegeri diferite (A2–B1)

Mai întâi, **uzul toponimic** stabilește tipul de caz (interior <span lang="hu">`-ban/-ben`</span> sau exterior <span lang="hu">`-on/-en/-ön/-n`</span>); abia apoi armonia vocalică intervine în forma concretă a sufixului.

| Localitate | Hol? – Unde? | Hová? – Încotro? | Honnan? – De unde? |
|---|---|---|---|
| București – <span lang="hu">`Bukarest`</span> | <span lang="hu">`Bukarestben`</span> | <span lang="hu">`Bukarestbe`</span> | <span lang="hu">`Bukarestből`</span> |
| Cluj – <span lang="hu">`Kolozsvár`</span> | <span lang="hu">`Kolozsváron`</span> | <span lang="hu">`Kolozsvárra`</span> | <span lang="hu">`Kolozsvárról`</span> |
| Timișoara – <span lang="hu">`Temesvár`</span> | <span lang="hu">`Temesváron`</span> | <span lang="hu">`Temesvárra`</span> | <span lang="hu">`Temesvárról`</span> |
| Budapesta – <span lang="hu">`Budapest`</span> | <span lang="hu">`Budapesten`</span> | <span lang="hu">`Budapestre`</span> | <span lang="hu">`Budapestről`</span> |

**Important:** deosebirea <span lang="hu">`Bukarestben`</span> / <span lang="hu">`Budapesten`</span> **nu provine numai din armonia vocalică**: aici se folosesc chiar două cazuri locative diferite (inesiv și superesiv). Nici criteriul „oraș din fostul Regat al Ungariei” nu prezice singur cazul fiecărei localități.

### Procedură practică de alegere a sufixului

1. **Identifică funcția gramaticală.** Vrei „în”, „către”, plural, dativ sau altceva? Sufixele armonice nu sunt interschimbabile semantic.
2. **Stabilește dacă sufixul variază.** Dacă este <span lang="hu">`-ig`</span>, <span lang="hu">`-ért`</span>, <span lang="hu">`-kor`</span> ori <span lang="hu">`-ni`</span>, nu ai de ales o variantă vocalică.
3. **Privește rădăcina (și sufixele deja adăugate).** Există vocale posterioare (<span lang="hu">`a á o ó u ú`</span>) sau anterioare rotunjite (<span lang="hu">`ö ő ü ű`</span>)?
4. **Dacă sufixul are trei variante**, verifică și rotunjirea locală: <span lang="hu">`-hoz / -hez / -höz`</span>.
5. **Dacă apar <span lang="hu">`i í é e`</span>**, verifică transparența, eventualele vocale posterioare anterioare și clasa lexicală a cuvântului.
6. **Memorează excepțiile și variația**, precum <span lang="hu">`hídnak`</span>, <span lang="hu">`férfival / férfivel`</span>. La plural și acuzativ verifică și clasa flexionară.
7. **Pentru orașe, alege mai întâi cazul tradițional** (<span lang="hu">`-ban/-ben`</span> ori <span lang="hu">`-on/-en/-ön`</span>), apoi aplică armonia.

## 15. Exerciții gradate, cu rezolvări

### A1 – Alege -ban sau -ben

1. <span lang="hu">`ház`</span> → ... (în casă)
2. <span lang="hu">`kert`</span> → ... (în grădină)
3. <span lang="hu">`tűz`</span> → ... (în foc)
4. <span lang="hu">`iskola`</span> → ... (în școală)

### A2 – Alege -hoz / -hez / -höz

5. <span lang="hu">`ház`</span> → ...
6. <span lang="hu">`szék`</span> → ...
7. <span lang="hu">`tűz`</span> → ...
8. <span lang="hu">`könyv`</span> → ...

### B1 – Identifică regula și sufixul

9. <span lang="hu">`papír`</span> + dativ → ...
10. <span lang="hu">`kávé`</span> + inesiv → ...
11. <span lang="hu">`híd`</span> + dativ → ...
12. <span lang="hu">`könyvek`</span> + „către” → ...

### B2–C1 – Explică fenomenul

13. De ce <span lang="hu">`házak`</span>, dar <span lang="hu">`gázok`</span>, deși ambele au <span lang="hu">`á`</span>?
14. De ce <span lang="hu">`könyvhöz`</span>, dar <span lang="hu">`könyvekhez`</span>?
15. De ce nu este suficientă formula „privește ultima vocală” pentru <span lang="hu">`papírnak`</span> și <span lang="hu">`koncerten`</span>?
16. Cum diferă alegerea cazului în <span lang="hu">`Bukarestben`</span> și <span lang="hu">`Budapesten`</span> de armonia propriu-zisă?

**Rezolvări:**

1. <span lang="hu">`házban`</span>; 2. <span lang="hu">`kertben`</span>; 3. <span lang="hu">`tűzben`</span>; 4. <span lang="hu">`iskolában`</span> (cu <span lang="hu">`a → á`</span>).
5. <span lang="hu">`házhoz`</span>; 6. <span lang="hu">`székhez`</span>; 7. <span lang="hu">`tűzhöz`</span>; 8. <span lang="hu">`könyvhöz`</span>.
9. <span lang="hu">`papírnak`</span> (transparența lui <span lang="hu">`í`</span>); 10. <span lang="hu">`kávéban`</span> (transparența lui <span lang="hu">`é`</span>); 11. <span lang="hu">`hídnak`</span> (antiharmonie); 12. <span lang="hu">`könyvekhez`</span> (rotunjire locală).
13. Clasa flexionară / <span lang="hu">*nyitótő*</span>, nu numai armonia. 14. Pluralul introduce <span lang="hu">`e`</span>, care influențează sufixul următor. 15. <span lang="hu">`í`</span> poate fi transparent, în timp ce comportamentul lui <span lang="hu">`e`</span> este mai variabil și lexical. 16. Mai întâi se alege cazul locativ convenționalizat, apoi varianta armonică a sufixului.

### Fișa foarte scurtă (de repetat în 30 de secunde)

- **Posterioare:** <span lang="hu">`a á o ó u ú`</span> → de obicei <span lang="hu">`-ban`</span>, <span lang="hu">`-hoz`</span>, <span lang="hu">`-on`</span>.
- **Anterioare nerotunjite:** <span lang="hu">`e é i í`</span> → frecvent <span lang="hu">`-ben`</span>, <span lang="hu">`-hez`</span>, <span lang="hu">`-en`</span>, **dar** unele sunt neutre și transparente.
- **Anterioare rotunjite:** <span lang="hu">`ö ő ü ű`</span> → frecvent <span lang="hu">`-ben`</span>, <span lang="hu">`-höz`</span>, <span lang="hu">`-ön`</span>.
- **Vocale neutre:** <span lang="hu">`i í é e`</span>; nu te baza orbește pe ultima vocală.
- **Excepții:** <span lang="hu">`hídnak`</span>, <span lang="hu">`papírnak`</span>, <span lang="hu">`férfival/férfivel`</span>; unele forme se învață lexical.
- **Sufixe fixe:** <span lang="hu">`-ig`</span>, <span lang="hu">`-ért`</span>, <span lang="hu">`-kor`</span>, <span lang="hu">`-ni`</span>.
- **Pluralul:** <span lang="hu">`házak`</span>, <span lang="hu">`kertek`</span>, <span lang="hu">`gázok`</span>, <span lang="hu">`kürtök`</span> — intervine și clasa flexionară.
- **Localitățile:** alegerea <span lang="hu">`-ban/-ben`</span> sau <span lang="hu">`-on/-en/-ön`</span> este uneori tradițională; armonia stabilește varianta **în interiorul** seriei alese.
