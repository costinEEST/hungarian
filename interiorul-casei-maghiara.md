# Interiorul casei în limba maghiară — vocabular A1

Vocabular organizat tematic pentru începători. Cuvintele maghiare sunt scrise în forma de bază; pronunția este **aproximativă, adaptată unui vorbitor de română**, nu o transcriere IPA.

## Legendă de pronunție

- Accentul cade pe **prima silabă** a cuvântului maghiar, indiferent de lungimea lui.
- **sz** = **s** românesc; **s** = **ș**; **cs** = **ci** (ca în „cine”); **c** = **ț**; **zs** = **j** românesc; **ly** = **i** consonantic.
- **á** ≈ **a** lung (notat `aa`); **é** ≈ **e** lung și mai închis (notat `ee`); **í, ó, ú** = vocale lungi (`ii, oo, uu`). Litera **a** scurtă maghiară este un sunet între „a” și „o” românesc, notat orientativ **o**.
- **ö/ő** și **ü/ű** nu au corespondente exacte în română: păstrăm simbolurile maghiare în coloana de pronunție. **ő** și **ű** sunt variante lungi. Pentru **ö**, rostește „e” cu buzele rotunjite ca pentru „o”; pentru **ü**, rostește „i” cu buzele rotunjite ca pentru „u”.
- **gy** este o consoană palatală, redată aproximativ prin `di` (sau `dj` foarte moale), **ny** ≈ `ni` palatalizat, **ty** ≈ `ti` palatalizat. Aceste echivalări nu sunt perfecte.
- **j** = „i” consonantic, ca în „iar”; **y** apare mai ales în grupuri consonantice; **h** se aude; consoanele duble se rostesc mai lung.
- Separatoarele `-` din pronunții ajută la citirea cuvintelor compuse, nu indică accentul.

## 11. Cuvinte compuse

Ultimul element indică de obicei tipul obiectului: `szoba` = cameră, `gép` = mașină/aparat, `szekrény` = dulap. Primul element precizează destinația. Tabelul arată structura cuvintelor, nu etimologia lor istorică.

| Maghiară      | Elemente                                     | Română                |
| ------------- | -------------------------------------------- | --------------------- |
| hálószoba     | háló (de dormit) + szoba (cameră)            | dormitor              |
| fürdőszoba    | fürdő (de baie) + szoba (cameră)             | baie                  |
| íróasztal     | író (de scris) + asztal (masă)               | birou                 |
| könyvespolc   | könyves (pentru cărți) + polc (raft)         | raft de cărți         |
| ruhásszekrény | ruhás (pentru haine) + szekrény (dulap)      | dulap pentru haine    |
| hűtőszekrény  | hűtő (care răcește) + szekrény (dulap)       | frigider              |
| mosogatógép   | mosogató (pentru spălat vase) + gép (mașină) | mașină de spălat vase |
| fogkefe       | fog (dinte) + kefe (perie)                   | periuță de dinți      |
| porszívó      | por (praf) + szívó (care aspiră)             | aspirator             |

În `ruhás + szekrény → ruhásszekrény` se păstrează ambii s. Sensul uzual nu este mereu literal: `dohányzóasztal` înseamnă „măsuță de cafea”, deși `dohányzó` se referă la fumat.

## 12. Forme utile în propoziții

Articolul hotărât este `a` înaintea unei consoane (`a szék` = scaunul) și `az` înaintea unei vocale (`az ablak` = fereastra). `egy` înseamnă „un/o”.

Sufixele se scriu lipite de cuvânt. În exemplele de mai jos, a și e finale devin á și é. La cuvintele compuse, ultima componentă determină de obicei varianta sufixului: `fürdőszoba → fürdőszobában`.

| Cuvânt     | Unde? (în)    | Încotro? (spre interior) | De unde? (din interior) |
| ---------- | ------------- | ------------------------ | ----------------------- |
| szoba      | szobában      | szobába                  | szobából                |
| konyha     | konyhában     | konyhába                 | konyhából               |
| fürdőszoba | fürdőszobában | fürdőszobába             | fürdőszobából           |
| szekrény   | szekrényben   | szekrénybe               | szekrényből             |
| pince      | pincében      | pincébe                  | pincéből                |

Pentru suprafețe: `asztalon` = pe masă, `asztalra` = pe masă (direcție), `asztalról` = de pe masă. Postpozițiile se scriu separat: `az asztal mellett` = lângă masă.

Pluralul are de obicei terminația -k, uneori cu o vocală de legătură: `ház → házak`, `szék → székek`, `szoba → szobák`.

Posesia se exprimă prin terminații: `házam` = casa mea, `szobám` = camera mea, `könyvem` = cartea mea.

Complementul direct primește -t, uneori cu o vocală de legătură: `ablak → ablakot`, `ajtó → ajtót`. De aici forma din `Nyisd ki az ablakot!` = Deschide fereastra!
