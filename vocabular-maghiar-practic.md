# Vocabular maghiar practic – 982 de cuvinte și expresii

## Cum se citește pronunția

Accentul cade **întotdeauna pe prima silabă**.

| Literă HU      | Scris în RO    | Cum se pronunță                                                  |
| -------------- | -------------- | ---------------------------------------------------------------- |
| a              | o              | „o” deschis, între „a” și „o” (ex. *magyar* → moghior)           |
| á              | aa             | „a” lung                                                         |
| e              | e              | „e” deschis                                                      |
| é, í, ó, ú     | ee, ii, oo, uu | vocale lungi: ține sunetul de două ori mai mult                  |
| ö / ő          | ö / öö         | „e” rostit cu buzele rotunjite (ca în germană *schön*); ő e lung |
| ü / ű          | ü / üü         | „i” rostit cu buzele rotunjite (ca în germană *müde*); ű e lung  |
| c              | ț              | *cukor* → țukor                                                  |
| cs             | c / ci         | ca în „cer”, „cioc”                                              |
| s              | ș              | *só* → șoo                                                       |
| sz             | s              | *szép* → seep                                                    |
| zs             | j              | *rizs* → rij                                                     |
| gy             | ghi            | ca în „ghiată”; la final, scurt, ca în „unghi”                   |
| ty             | chi            | ca în „chiar”; la final, ca în „ochi”                            |
| ny             | ñ              | ca „ñ” în spaniolă (*España*)                                    |
| j, ly          | i              | ca „i” din „iarnă” (*jó* → ioo)                                  |
| g + e/i        | ghe / ghi      | *igen* → ighen                                                   |
| consoane duble | dublate        | se țin puțin mai mult (*kettő* → kettö)                          |

> Verbele sunt date la infinitiv (terminația **-ni**). În dicționare apar de obicei la persoana a III-a singular (ex. *megy* = merge).
